Fun fact: the repo behind this site was created in September 2020 and then sat untouched for almost six years, serving a default "Welcome to GitHub Pages" placeholder to nobody.

So this is attempt number two. The theory this time: lower the bar. Not every entry needs to be an essay — a book note, a half-formed thought, or a two-line "today I learned" all count. The goal is a place to think out loud, not a publication.

We'll see how it goes.
